## A little about me

I’m **Ridjan**, an Epitech student exploring the space between **systems programming, cybersecurity, and useful applications**. I like following an idea all the way down: from the interface someone clicks to the code and operating system underneath it.

My projects range from a Rust pixel editor to a voice companion for Linux. CTFs give me another way to learn: inspect a problem, test an idea, and keep digging until the pieces make sense.

| On my desk | What draws me in |
| :--- | :--- |
| **Building JKI / Jake** | Local speech recognition, desktop controls, and a voice interface for Codex. |
| **Exploring systems** | C, Rust, Linux, and understanding what happens behind an abstraction. |
| **Learning through CTFs** | Reverse engineering, security puzzles, and practical problem solving. |
| **Outside the terminal** | Anime soundtracks, music on repeat, and ideas for the next project. |
